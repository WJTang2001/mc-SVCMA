Model Averaging for Multi-class Support Vector Classifier


Abstract

All of the data processing and analysis for this paper were done in R. This repository contains the R scripts for the simulation study and empirical analysis  in the paper "Model Averaging for Multi-class Support Vector Classifier".

Description

All codes for the simulation studies and empirical analysis are contained in the two files. A detailed description of each script is provided below.

##############  scripts for simulation  ######################
(1) functions.R ---an R script for some basic functions including the data generating process
(2) simulation.R ---an R script for Table 2 and Figure 2 (Simulation studies)
(3) script for weight consistency.R ---an R script for Figure 4 (Simulation studies)

##############  scripts for real data  ######################
(1) empirical analysis.R ---an R script for Figure 5 in Section 5 on the gearbox fault diagnosis dataset

Optional Information

The following R packages are necessary to successfully run the scripts:

(1) caret version 6.0-94 (https://cran.r-project.org/web/packages/caret)
(2) ggplot2 version 3.5.0 (https://cran.r-project.org/web/packages/ggplot2)
(3) reshape2 version 1.4.4 (https://cran.r-project.org/web/packages/reshape2)
(4) pROC version 1.18.5 (https://cran.r-project.org/web/packages/pROC)
(5) gridExtra version 2.3 (https://cran.r-project.org/web/packages/gridExtra)
(6) RColorBrewer version 1.1-3 (https://cran.r-project.org/web/packages/RColorBrewer)
(7) PRROC version 1.3.1 (https://cran.r-project.org/web/packages/PRROC)
(8) LiblineaR version 2.10-13 (https://cran.r-project.org/web/packages/LiblineaR)
(9) nloptr version 2.1.1 (https://cran.r-project.org/web/packages/nloptr)
(10) mvtnorm version 1.2-4 (https://cran.r-project.org/web/packages/mvtnorm)



Instructions for Use

The scripts provided can be used to reproduce the results in the simulation and empirical analysis sections, including tables and figures.

First, install and load the required R packages listed above.

Second, to reproduce the simulation results, put all the files provided in the working directory and execute the following commands in R:

source("functions.R")
source("simulation.R")

Third, to reproduce the real data analysis results:

source("empirical analysis.R")
